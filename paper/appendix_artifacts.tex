\subsection*{Certified/verified claims checked by the verifier}

\begin{itemize}
  \item \textbf{Integrity:} SHA256 of all four artifacts matches this appendix and \texttt{paper/artifacts.json}.
  \item \textbf{Termination:} \texttt{rank.dat} is a ranking certificate; the verifier checks
        $rank(\mathrm{Next}(s)) < rank(s)$ on a fixed random sample of live edges.
  \item \textbf{No lower escape from semantic starts:} from the semantic start set $(d=0,r=0)$, no state can reach
        \texttt{exit\_low} (equivalently, \texttt{hit\_r0 = 0}).
  \item \textbf{\texttt{exit\_high} descent (FULL):} for every \texttt{exit\_high} kill state, the odd-only step
        produces strict descent in $\mathbb{N}$.
  \item \textbf{\texttt{shrink} descent (FULL, 2-step):} for every \texttt{shrink} kill state, if $n_1=F(n)$ then
        $n_1\equiv 1\pmod 8$, and if $n_1>1$ then $F(n_1)<n_1$.
\end{itemize}
